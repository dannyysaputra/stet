Stet

A design reviewer for apps built by AI coding agents. It reads every label, button and message on a screen, checks it on your laptop, pins what is wrong, and gives your agent one prompt to fix it. Your app's text stays on your laptop.

1. The laptop model

Stet checks text with the model built into Chrome (Gemini Nano), on this computer, through Firebase AI Logic. Nothing you review is sent anywhere for that.

Checking this browser...

Without the laptop model

Chrome desktop 139 or newer can run it; it needs about 22 GB of free disk space. Without it, an Open project still works: Stet shows you the exact strings first, and sends them to the cloud model only after you approve. A Sealed project never sends its text, so it waits for the laptop model.

In Chrome, turn on chrome://flags/#prompt-api-for-gemini-nano-multimodal-input, restart Chrome, then download the model here.
